# VISITORS — Repo Documentation Pack

This folder is the starting documentation set for **VISITORS**, a first-person dungeon-guardian game built in Three.js.

The purpose of these documents is twofold:

1. Give Codex narrow, buildable instructions for the first prototype.
2. Preserve the larger idea so the project does not get reduced into a generic dungeon crawler.

## Current working premise

You are the Guardian: an Egyptian priest-warrior selected by the Anunnaki to protect an artifact connected to the Visitors. You are trapped in the tomb across fictional ages. Every 600 years, new invaders enter seeking the tomb’s power, treasure, secrets, or relic. They are the “visitors” in your home. The Visitors are also the ancient owners of the artifact.

The player does not play as the hero. The hero is the threat.

## Current prototype name

The first playable area is called the **Test Tomb**.

It is not the final first dungeon. It exists to prove the central game loop:

**Visitor enters. Guardian kills. Guardian drags corpse. Tomb feeds. Guardian upgrades. Next visitor arrives.**
